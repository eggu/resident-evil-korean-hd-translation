# Source reference

`encoding.xml` is the original character mapping from RE1 Mod SDK:
https://github.com/Gemini-Loboto3/RE1-Mod-SDK/blob/875af9b198308ffb7d3a74d4fe34bbbd91778b48/xml/encoding.xml

It is input to the generator, not a generated Korean subtitle resource. The generated mod mapping lives only under `build/mod_korean_translation/encoding.xml`.
